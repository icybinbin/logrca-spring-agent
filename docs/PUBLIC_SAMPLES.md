# 公开 Spring/Hikari 日志样例

文件：`data/public_hikari_1546_excerpt.log`。

来源：[HikariCP官方仓库的公开Issue #1546](https://github.com/brettwooldridge/HikariCP/issues/1546)。这是用户公开报告的日志节选，包含连接获取超时和Spring/Hikari调用栈；该报告没有确认最终根因。

摘录只保留原报告的一条ERROR和两条已有栈帧，顺序保持不变，其余日志与栈帧省略。没有补造服务名、trace_id、时间或故障结论。原帖中的拼写和截断保留，文件行号对应本节选文件，不能当作原报告的行号。来源位置、摘要SHA256和处理记录在 `data/public_hikari_1546_source.json`。

网页选择“公开故障日志节选 · HikariCP”，或者选择上传并打开这个文件。先用离线方式确认解析、证据核对和下载流程，再切换DeepSeek运行。

本样例能支持“未能从连接池取得连接”的判断。仅凭此摘录不能判断是连接泄漏、慢SQL、数据库不可用还是其他原因；补充原因应作为下一步检查。文件没有时区和trace_id，页面会提示时区假设并使用时间窗分组。

这些公开资料用于功能验证和学习，不是本项目独立采集的公司生产数据，也不是带完整根因真值的评测集。发布包中保留来源说明，避免把一次诊断成功写成生产准确率。
